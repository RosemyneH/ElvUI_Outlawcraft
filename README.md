## Install

</div>

1. Download the zip from the [latest release](https://github.com/RosemyneH/ElvUI_Outlawcraft/releases/latest).
2. Extract every `ElvUI*` folder into `Interface\AddOns` on your **OutlawCraft** client.
3. Restart World of Warcraft and run `/ec`.

Keep the folder names as they are. Do not nest them inside another directory.

## Pack

| Addon | What it is |
| :---: | :--- |
| **ElvUI** | Core UI replacement |
| **ElvUI_OptionsUI** | In-game configuration (`/ec`) |
| **ElvUI_AddOnSkins** | Skins for popular addons |
| **ElvUI_Enhanced** | Extra quality-of-life modules |
| **ElvUI_EnhancedFriendsList** | Friends list improvements |
| **ElvUI_ExtraActionBars** | Additional action bars |
| **ElvUI_DTBars2** | Extra data text bars |
| **ElvUI_PartyDamage** | Incoming damage next to party frames |

## OutlawCraft

</div>

- The **OutlawCraft** skin restyles every OutlawCraft window (lockboxes, loot, crafting, clans, bounty board, guide and the rest) in ElvUI's media, fonts and colours.
- `/ec` → Outlaw toggles the skin, the spellbook **Crafting** tab, tooltip styling, the loot frame, and the exposure meter.
- Datatexts under `/ec` → DataTexts: **Hunger**, **Thirst**, **Hunger Regen**, **Food & Water** and **Exposure**.

## Releases

</div>

Every merge to `main` is scanned for [Conventional Commits](https://www.conventionalcommits.org/). When there are releasable changes, a release pull request is opened with an updated changelog. Merging that PR tags a GitHub Release and attaches an AddOns zip.

| Prefix | Version bump | Example |
| :---: | :---: | :--- |
| `feat:` | minor | `feat: add party damage icons` |
| `fix:` | patch | `fix: nameplate alpha in combat` |
| `feat!:` or `BREAKING CHANGE:` | major | `feat!: drop legacy layout` |
| `docs:`, `chore:`, `ci:` | no release | `docs: clarify install steps` |
